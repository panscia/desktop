# Panscia desktop — releases

Signed builds of the Panscia node for macOS and Windows, published here as
GitHub Releases. Installed apps read `latest-mac.yml` or `latest.yml` from
the latest published release to update themselves.

Download from [panscia.com/download](https://panscia.com/download), which
picks the build for your computer.

Source is not kept in this repository.
